## Install

Install the fork under the name `sst`, so `import ... from "sst"` keeps working.

```bash
npm install sst@npm:@sst-community/sst
```

To switch an existing project from SST, change its dependency to `"sst": "npm:@sst-community/sst@<version>"` and reinstall. Without Node:

```bash
curl -fsSL https://raw.githubusercontent.com/sst-community/sst/main/install | bash
```

## What's different

Each [release](https://github.com/sst-community/sst/releases) lists what it changes from the upstream version it's based on. Otherwise these docs are SST's own, built from this repo.
